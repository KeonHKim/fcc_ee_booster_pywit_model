# FCC-ee HEB impedance and wake model

## Start with the V26.2 published release

The ready-to-use impedance and wake files are in [HEB_IW_2026/HEB_IW_2026_V26_2](HEB_IW_2026/HEB_IW_2026_V26_2/README.md).

The release is organized to match the FCC-ee main-ring style, with **Impedances**, **Wakes**, **Plots**, **Simulation_files**, and **Utilities&Docu**.

The original Python package (`fcc_ee_booster_pywit_model/`), `Example/` notebooks, and historical data remain unchanged.

For ready-made beam dynamics input, use the V26.2 **Impedances/Total** and **Wakes/Total** folders, and consult the release README about signs, units, normalization, and provisional assumptions.
